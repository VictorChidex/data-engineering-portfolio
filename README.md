## ⚙️ Azure Data Engineering Stack

### ☁️ **Cloud Platform**
- **Microsoft Azure** — Cloud ecosystem  
- **Azure Portal** / **Azure CLI** — Resource management and automation  

### 🗂️ **Data Storage & Lakehouse**
- **Azure Data Lake Storage Gen2 (ADLS Gen2)** — Raw, curated, and analytics zones  
- **Azure Blob Storage** — Unstructured and semi-structured data  
- **Delta Lake** — ACID-compliant data management on Databricks  

### 🔄 **Data Ingestion & Integration**
- **Azure Data Factory (ADF)** — Data orchestration and ETL  
- **Event Hub** — Streaming data ingestion  
- **Synapse Pipelines** — Hybrid orchestration  

### 🔥 **Data Processing & Transformation**
- **Azure Databricks** — PySpark notebooks and jobs  
- **Apache Spark / PySpark** — Distributed processing  
- **Azure Synapse Analytics (SQL Pools)** — ELT and analytical transformations  

### 💾 **Programming Stack**
#### 🧠 **SQL Stack**
- **Core Skills:** T-SQL, Synapse SQL, Window Functions, CTEs, Stored Procedures  
- **Use Cases:** Data modeling, transformations, analytics queries, performance tuning  
- **Folder:** [`09-Learn-SQL`](./09-Learn-SQL/README.md)

#### 🐍 **Python Stack**
- **Core Skills:** Pandas, PySpark, NumPy, SQLAlchemy, Azure SDKs  
- **Use Cases:** ETL scripting, data wrangling, pipeline development, Databricks notebooks  
- **Folder:** [`10-Learn-Python`](./10-Learn-Python/README.md)

### 📊 **Data Visualization & Reporting**
- **Power BI** — Dashboards and insights  
- **Synapse Serverless SQL** — Query layer for Power BI  

### 🛡️ **Governance, Security & DevOps**
- **Azure Purview** — Data catalog and lineage  
- **Azure Key Vault** — Secure secrets and credentials  
- **Azure Monitor / Log Analytics** — Monitoring and alerts  
- **Azure DevOps / GitHub Actions** — CI/CD and automation
